# 自动搭路 (AutoBridge)

按住右键往前走，**自动在脚前那格铺方块**。横穿峡谷、岩浆、虚空不用再回头蹲下、
准星对着脚下方块、一边退一边点了。

- Minecraft **26.4-snapshot-5** / Fabric Loader 0.19.5+ / Fabric API
- 单人存档和联机都支持（要自动搭路的话，两边都装）

## 下载

到 [Releases](https://github.com/2006522/autobridge/releases) 页面下载最新的
`AutoBridge-<版本号>.jar`。

## 安装

1. 安装 [Fabric Loader](https://fabricmc.net/use/)（0.19.5+）和 [Fabric API](https://modrinth.com/mod/fabric-api)；
2. 将 jar 放入实例的 `mods/` 目录（**客户端和服务端都要放**）；
3. 启动游戏。

> 同一个 mod id 只能存在一份 jar，升级时请先删掉旧版本，否则加载会报重复 id。

## 用法

1. 快捷栏里带上垫脚的方块（**完整方块**，圆石/泥土/木板都行）；
2. **朝前走，按住右键**。

脚前缺的那一格会被补上，你直接踩过去就行。不用回头、不用蹲、不用看脚下。

关了就按 `B`，屏幕下方会闪一下「自动搭路 已开启 / 已关闭」。

### 准星下方的倒三角

准星正下方常驻一个小倒三角，随时告诉你「现在按右键会不会铺」：

| 显示 | 意思 |
| --- | --- |
| **亮青色（会呼吸）** | 立刻铺 —— 前面真的断了，手里也有砖 |
| **淡灰色** | 暂时不会铺 —— 没在走 / 前面有地面 / 手头没有能当砖的方块 |

它在界面打开（`E`、`Esc`）、F1 隐藏界面、旁观模式时都不显示。觉得挡视线可以在设置里关掉。

### 目标方块轮廓

条件成立时，脚前那一格会圈一圈青蓝色方框 —— 那就是接下来会放方块的位置。
和倒三角互补：三角说"会不会铺"，轮廓直接告诉你"铺哪儿"。

### 什么时候不会介入

只有同时满足这几点它才动手，其它情况一律按原版来：

- 脚前那一格是空的；
- 脚前那一格**下面也是空的**（说明前面真的断开了，不是平地或台阶）；
- 手头或快捷栏里找得到能当砖的完整方块；
- 你正在移动（站着不动右键还是正常放方块）。

所以蹲着修房子、贴着墙摆方块、在平地上乱点，都不会被它抢走操作。

## 按键

| 按键 | 功能 |
| --- | --- |
| `B`（默认） | 开关自动搭路 |
| `H`（默认） | 打开设置界面 |

可以在「选项 → 控制 → 按键绑定」里改。

## 设置界面

按 `H` 打开，改一项立刻生效、立刻存盘（没有「保存」按钮，只有「完成」）。
想恢复出厂设置点「恢复默认」。

界面里能调的东西：

| 分组 | 选项 | 说明 |
| --- | --- | --- |
| 搭路 | 总开关 | 同 `B` 键 |
| 搭路 | 只在移动时铺 | 站着不动时右键按原版走 |
| 搭路 | 仅潜行时铺 | 更保守，必须蹲着走才铺 |
| 搭路 | 只认完整方块 | 不拿种子、树苗、火把、台阶当砖 |
| 搭路 | 铺路间隔 | 0~20 刻，调大可以放慢铺路节奏 |
| 显示 | 准星倒三角 | 开关那个提示 |
| 显示 | 目标方块轮廓 | 开关目标格的方框 |

## 配置文件

设置界面读写的就是 `config/autobridge.properties`，手改也生效（下次启动读取）。

```properties
# 总开关
enable=true

# 只在移动时铺（关掉的话站着不动也会往脚前放一格）
need_moving=true

# 只拿完整方块当铺路材料，避免把种子、树苗、火把、台阶当砖用掉
require_full_block=true

# 准星下方的倒三角提示
crosshair_hint=true
# 三角颜色，ARGB（不写 alpha 按不透明算）
hint_color=0xFF5CDBFF

# 目标方块轮廓
show_outline=true
outline_color=0xFF5CDBFF

# 两次铺路之间至少间隔多少刻（0 = 每刻都铺）
place_delay=0

# 只在潜行时铺
only_when_sneaking=false
```

## 已知限制

- **右键会被接管**：搭路条件成立时，这一次右键只用于铺路，原版的放置不再执行
  （否则一次会放两块）。想正常放方块，停下来别动，或者按 `B` 关掉。
- 材料优先用主手，其次副手，再其次快捷栏前 9 格。
- 只往**水平方向**铺一格（一格高、一格宽），上坡下坡不会自动垫台阶。
- 「前方」按你**实际走的方向**算：侧身沿崖边平移、倒退着走都能铺对；完全停下时才用面朝方向。
